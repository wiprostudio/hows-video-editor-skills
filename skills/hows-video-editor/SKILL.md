# HOW's video editor — experimental

Status: candidate, not approved for agent rollout.

## Brief and scope

Owner communication and script review use Indonesian. Final audience is US viewers; adapt approved narration into natural American English. A request for a test or review authorizes a local preview or storyboard, not automatically a paid end-to-end generation. Follow explicit user overrides.

Use original editorial mixed-media collage: navy, off-white, restrained coral accents, paper texture, legible typography. Paper diorama is optional for reconstructions. Treat Vox as a broad reference, not affiliation or a requirement to copy branding or sequences.

Shorts default to 9:16, 35–60 seconds; long episodes to 16:9, 8–12 minutes. These are adjustable planning ranges, not measured retention optima. Preserve the requested runtime and format.

## Production playbook

For a new episode, read [references/production-workflow.md](references/production-workflow.md). Use [STYLE.md](STYLE.md) for provisional HOW's visual defaults and copy [templates/TREATMENT.md](templates/TREATMENT.md) into the episode folder for timed planning. These resources adapt the owner-supplied tutorial; they do not override the current request.

## Select the production route

Inspect the current project and available tools first.
- Existing Remotion project: follow its local instructions and use reusable compositions for text, timelines, maps, cutouts and charts. Check its installed version and actual render commands. Do not assume the runtime is installed.
- Higgsfield requested: use its available workflow discovery and current schemas. Verify model, preset, voice and asset availability. Old job IDs, prices, and field names in the upstream archive are historical examples, not working credentials or current contracts.
- No renderer ready: create a storyboard and asset manifest. Report the missing dependency honestly; do not present a planning file as a rendered video.

Do not install frameworks, switch services, or incur costs merely to review this skill. When paid generation is requested, check current cost estimates, disclose the planned scope, and remain within the user's authorized budget. Missing authorization must be resolved before spending.

## Editorial preparation

For factual narration, inspect sources before drafting claims. Record claim, source URL, event date and uncertainty. Prefer primary sources and corroborate contested material. Never reuse the upstream food-waste or shipping figures as verified evidence.

Review Indonesian narration before producing the full English adaptation unless the user explicitly authorizes immediate English. Editing already approved English does not require a new translation review.

Each scene should advance a question, evidence, mechanism or consequence. Use a recurring metaphor only when useful. Do not force a twist, a whip-pan, or an impact every three seconds. Give the promised answer and preserve uncertainty in unresolved cases.

## Storyboard and assets

Record scene ID, narration, estimated duration, visual action, text, assets, source/claim IDs and reconstruction status. Separate timing estimates from measured audio duration.

Use source-derived data for charts and preserve scale, units, labels and dates. Decorative graphics must not imply measured quantities. Mark reconstructions and illustrative AI assets; do not invent documentary evidence or quotes.

Put precise text, captions, dates and chart labels in the editor whenever possible. Generated scene lettering is optional decoration and must be checked visually. Check licenses and provenance of external assets before final delivery.

## Production and verification

Use final narration audio as the timing reference. Ten-second blocks are an optional generation constraint, not a required narrative rhythm. Keep one narrator and match pacing without aggressive speed-up.

Set the requested aspect ratio explicitly when supported. Inspect actual dimensions and duration before assembly. If output has the wrong framing, correct or regenerate it within the authorized scope; do not silently change the deliverable.

Generate only needed assets, record job IDs per scene, and check failed jobs before bounded retries. For moderation rejection, use a compliant alternative or explain the limit; do not switch models to evade a safety restriction.

Assemble a complete MP4 when the user requested a finished video and the tools permit it. For a test, deliver the explicitly scoped preview. Inspect representative frames, captions and final duration; listen for clipping, narration gaps and excessive music. Report checks actually performed and unresolved issues.

Deliver the preview/video, editable sources when available, source list, and concise validation notes. Do not claim publication, rendering or testing succeeded without observable output. Publishing and rollout to another agent are separate user-directed actions.
