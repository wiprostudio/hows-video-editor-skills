# HOW's visual direction — provisional

Use this for HOW's productions unless the owner supplies a different brief.
- Palette: navy #102D50, off-white #F4F0E8, coral #E66B52. These are proposed values, not sampled brand standards.
- Editorial 2D collage: paper cutouts, restrained textures, readable maps and timelines. Optional illustrated diorama reconstructions.
- Select and record licensed fonts before rendering; never silently substitute a missing font.
- Shorts: 1080x1920. Long episodes: 1920x1080. Default 30 fps; 60 fps when the motion or delivery brief benefits. These are editable production choices.
- Keep one dominant visual action per beat. Hold evidence long enough to read. Avoid perpetual zooms and mandatory whip transitions.
- Render factual labels and captions as editable text. Check safe areas against the target platform UI.
- Opening delivers the title/thumbnail promise. Logo/CTA placement follows the brief and should not delay the hook.
- Reconstruction is clearly distinguished from real source material.
