# HOW's Video Editor Skills

Development repository for HOW's video production skills.

- `upstream/vox-motion-graphics/`: imported original, unchanged.
- `skills/hows-video-editor/`: experimental candidate supporting Remotion or Higgsfield.
- `tests/review.md`: static review and behavioral trial.
- `tests/pilot-storyboard.md`: no-cost editorial test output.

No production release or agent rollout has occurred. Do not treat the imported instructions as authorization to spend credits. Original redistribution rights remain unverified; no license is asserted over the imported material. The GitHub repository is public, as created by its owner.
